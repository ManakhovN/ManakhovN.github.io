ManakhovN Tools Documentation

Documentation for ManakhovN Unity Editor Tools — editor extensions that streamline common Unity workflows.

Tools​

ToolWhat it doesAsset Store
Command LineEmbedded terminal for shell commands directly inside the Unity EditorEditor Terminal
Data Structures EditorVisual inspectors for JSON, XML, YAML, CSV, Markdown, and text files with editing capabilitiesData Structures Editor
Subtitles ToolRuntime subtitle system supporting SRT and ASS formatsSubtitles Player

Figma To Unity ImporterImports Figma nodes into uGUI — layouts, text, rendered images, and SVGFree, GitHub

Getting Started​

  1. Install the Tools: Buy the tool you need on the Unity Asset Store and import it through Window > Package Manager > My Assets
  2. Access Tools: Terminal opens from Tools > ManakhovN, the Git windows from Tools > VCSClient, and Files Converter from Window. Data Structures Editor needs no menu — it replaces the Inspector for supported files, and Subtitles Tool is a set of runtime components.
  3. Read Documentation: Browse the documentation for each tool to learn about features and usage

Requirements​

  • Unity Editor: 2020.3 LTS or later
  • .NET Framework: 4.7.1 or later (for some tools)
