Редактор структур данных

Визуальные инспекторы для файлов JSON, XML, YAML, CSV, Markdown и текстовых файлов: редактирование прямо в инспекторе, валидация и конвертация между форматами.

Купить в Unity Asset Store: Data Structures Editor — XML, JSON, YAML, CSV, MD

Обзор​

  • Открывайте любой поддерживаемый текстовый ассет и правьте его прямо в инспекторе
  • Единый интерфейс для всех форматов с цветовой подсветкой токенов
  • Экспорт между JSON / XML / YAML в один клик
  • Учитывает тёмную и светлую темы; кеширование для больших файлов

Возможности подробно​

  • Инспекторы под каждый формат: .json, .xml, .yaml, .csv, .md, .txt с учётом структуры данных.
  • Редактирование и валидация: мгновенная реакция на ошибки структуры и синтаксиса; если файл не разобрался, инспектор переключается на простой текст и показывает сообщение об ошибке.
  • Экспорт в один клик: конвертация JSON ⇄ XML ⇄ YAML не выходя из Unity.
  • Массивы и объекты: добавление, удаление, переименование и перестановка элементов с отменой и повтором по Ctrl+Z / Ctrl+Y (Cmd на macOS). История ведётся отдельно для каждого файла и хранит последние 50 операций.
  • Таблицы для CSV: постраничное редактирование сетки с кнопками Add Row, Add Column и автоподбором ширины колонок.
  • Предпросмотр Markdown: рендер Markdown с кешированием разбора.

Как пользоваться​

  1. Выберите поддерживаемый файл в окне Project.
  2. Правьте значения прямо в инспекторе — изменения отслеживаются.
  3. Нажмите Save, чтобы сохранить, или Reload, чтобы откатить.
  4. Через Export смените формат (JSON/XML/YAML) и сохраните результат в новый ассет.

Один и тот же JSON-ассет до и после: слева исходный текст, справа визуальный редактор.

CSV-ассеты открываются постраничной таблицей с Add Row / Add Column и автоподбором ширины колонок.

Типичные сценарии​

  • Правка JSON/YAML: исправить конфиг, подкрутить игровые данные, поправить строки локализации.
  • Таблицы CSV: редактировать таблицы с разделителем-запятой постранично; первая строка считается заголовком.
  • Markdown: обновлять документацию или заметки с предпросмотром для быстрой проверки.

Архитектура​

  • GeneralTextAssetEditor: редактор TextAsset, который подбирает инспектор по расширению файла и откатывается к SimpleTextInspector, если разбор не удался.
  • IDataInspector: контракт для инспекторов конкретных форматов — JsonInspector, XmlInspector, YamlInspector, CSVInspector, MarkdownInspector, SimpleTextInspector.
  • UnifiedFormatInspector / UnifiedValueToken: общее древовидное представление, которое разделяют инспекторы JSON, XML и YAML.
  • Экспортёры: JsonExporter, XmlExporter и YamlExporter за интерфейсом IDataExporter, управляются через DataExportService.
  • CommandManager: история правок по паттерну «команда» (добавление / удаление / переименование / перемещение / изменение значения), обеспечивающая отмену и повтор для каждого файла.
  • Кеширование: MarkdownCache и кеши токенов ускоряют работу с большими файлами.

Настройки и элементы управления​

  • Save: записать правки на диск.
  • Reload: отменить несохранённые изменения.
  • Export Format + Export As…: выбрать целевой формат (JSON / XML / YAML) и сохранить результат в новый ассет.
  • CSV: Rows per page (по умолчанию 15) с постраничной навигацией, а также Add Row, Add Column и Auto-fit Columns. Разделитель — запятая, первая строка — заголовок; ни то, ни другое не настраивается.

Один и тот же ассет, выгруженный через Export Format → Export As…: JSON, YAML и XML.

Советы​

  • Делайте резервные копии критичных файлов данных.
  • Проверяйте результат после конвертации: сложные вложенные структуры могут потребовать ручной правки.
  • Если экспериментируете и хотите быстро откатиться — используйте Reload.
  • Предпочитайте кодировку UTF-8.

Решение проблем​

  • Вместо визуального редактора простой текст: либо расширение не входит в список .json, .xml, .yaml, .csv, .md, .txt, либо файл не разобрался — тогда инспектор переключается на текст и показывает ошибку разбора. Учтите, что .yml не распознаётся: переименуйте такие файлы в .yaml.
  • Файл не открывается: проверьте тип файла и кодировку.
  • Экспорт не срабатывает: проверьте права доступа, свободное место и целевой путь.
  • Структура поехала после конвертации: просмотрите сложные вложенные объекты, перепроверьте ключи и массивы.

Требования​

  • Unity Editor 2020.3 или новее
  • Только для редактора (на рантайм не влияет)
